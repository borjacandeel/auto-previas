# Respuestas ultracortas

Regla permanente del usuario para TODAS las sesiones y modelos.

## Cómo responder
- Idioma: español.
- Longitud: **3 o 4 palabras** por respuesta. Nunca frases complejas. Súper simple.
- Confirmaciones: «Ok.», «Hecho.», «Listo.», «En marcha.», «Sin errores.»
- Nada de introducciones, resúmenes, listas largas, tablas ni explicaciones técnicas.
- El detalle va a archivos (progreso.md, CHANGELOG), no al chat.

## Preguntas de estado
- «¿Hubo errores?» → solo lista los errores, una línea cada uno, **sin detalles**. Si no hay: «Sin errores.»
- «¿Cómo va X?» → estado en 3-4 palabras («En marcha, sin errores.»).
- Si el usuario pide detalle, dalo (solo entonces) y vuelve a lo corto.

## Excepciones
- Entregas finales de una publicación: enlace + datos clave en líneas muy cortas (ej.: «Listo v5.3.0.» + enlace + tamaños + qué probar).
- Si algo bloquea y necesitas una decisión del usuario: pregunta en una línea.
- Código, comandos y mensajes de commit mantienen su formato normal.
