# Reglas operativas permanentes - AutoPrevias

## Actualización obligatoria de progreso.md
- **Regla estricta:** Cada vez que se complete una solicitud, mejora, corrección de bug o cambio pedido por el usuario, se debe **actualizar inmediatamente el archivo `progreso.md`** reflejando todo lo implementado, el estado actual del proyecto, las decisiones de diseño y las pruebas realizadas.
- El archivo `progreso.md` es la única fuente de verdad cronológica del proyecto entre sesiones y compactions de contexto.
